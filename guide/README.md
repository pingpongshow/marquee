# Marquee guide

Everything you need to install Marquee, set it up and use every setting, in the order you'll need it.

## Getting started

1. **[Install the server](install.md):** Docker or Unraid, hardware transcoding, folders and permissions, updating and backups.
2. **[First run](first-run.md):** the admin account, libraries, naming your files, metadata and the people in your household.
3. **[Apps and remote access](apps-and-remote.md):** installing the apps, signing in, Quick Connect, Tailscale and reverse proxies, and each person's own preferences.

## Settings, section by section

- **[Server settings](settings-server.md):** General, Users and profiles, Devices, Notifications and email, Webhooks, Scheduled Tasks, Dashboard, Statistics and Logs.
- **[Media settings](settings-media.md):** Libraries, Metadata, Transcoder, Music, AI, Cinema, Requests (Seerr and Bazarr), Plex import and sync, Library Health and the Large files optimizer.
- **[Live TV and DVR](live-tv-and-dvr.md):** sources, the guide, recordings, quotas and commercial cutting.
- **[VOD and Dispatcharr](vod-and-dispatcharr.md):** setting up Dispatcharr, films and shows on demand, saving them to your library, and suggestions.

## When something's wrong

- **[Troubleshooting](troubleshooting.md):** common problems and where to look.
